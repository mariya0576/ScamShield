# ScamShield 🛡️

ScamShield is a machine-learning powered web application that detects potential scams and phishing attempts in **text, URLs, emails, and documents**.

## Features

- 💬 Text scam detection
- 🔗 URL phishing detection
- 📧 Email analysis
- 📄 Document analysis
- ⚠️ Risk score and risk level
- 🔍 Scam indicators
- 🛡️ Safety recommendations
- 📋 Analysis history

## Technologies

- Python
- Flask
- Scikit-learn
- SQLite
- HTML
- CSS
- JavaScript

## Machine Learning

ScamShield uses trained machine-learning models to analyze suspicious content and identify potential scam or phishing patterns.

## How It Works

**User Input → Analysis → Risk Score → Detected Indicators → Safety Recommendation**
